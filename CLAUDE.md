## Project Overview

This is a **frontend development sandbox** for the Sandbox Angular application.

- **Frontend**: Angular 19 SPA (Single Page Application)
- **UI Framework**: Angular Material + TailwindCSS
- **Maps**: OpenLayers for geospatial features
- **i18n**: Transloco for internationalization
- **API Client**: Auto-generated TypeScript client via yasag from OpenAPI spec

The main frontend code is located in `sandbox/spa/`.

## Development Commands

### Running the Frontend

From the `sandbox` directory:

```bash
# Start frontend with Docker
make up-spa              # Runs on port 4200
```

Alternatively, run locally from `sandbox/spa/`:

```bash
npm install
npm run start            # Development server on port 4201
```

### Frontend Development

```bash
# Inside sandbox/spa/ directory
npm run start            # Development server on port 4201
npm run build            # Production build
npm run test             # Run Jasmine/Karma tests
npm run lint             # Lint code
npm run lint:fix         # Auto-fix linting issues
npm run prettier         # Format code with Prettier
```

### Working with Backend API

If you need to connect to the backend API or regenerate the API client:

```bash
# From sandbox directory
make up-api              # Start backend API on port 8000
make swagger             # Generate OpenAPI spec
make apigen              # Generate TypeScript API client
```

Access API docs at http://localhost:8000/swagger/ when backend is running.

## Authentication

This sandbox uses **standard Django REST Framework authentication**:

- **Token Authentication**: Primary method for API authentication
- **Session Authentication**: Available for browser-based testing
- **Endpoints**:
  - `POST /services/sandbox/auth/login/` - Login and get token
  - `POST /services/sandbox/auth/register/` - Register new user
  - `POST /services/sandbox/auth/logout/` - Logout (requires authentication)
  - `GET /services/sandbox/auth/me/` - Get current user info

### Using the API

Include the token in the Authorization header:
```
Authorization: Token <your-token-here>
```

Or use session authentication by logging in through the browsable API.

## Frontend Architecture

### Project Structure

The Angular application is located in `sandbox/spa/`:

- **src/app/** - Main application code
  - Components, services, modules
  - Feature modules organized by domain
- **src/api/** - Auto-generated TypeScript API client (generated by yasag from swagger.json)
- **src/assets/** - Static assets (images, i18n translations)
- **src/styles/** - Global styles and Tailwind configuration

### Key Technologies

- **Angular 19** - Latest Angular with standalone components support
- **Angular Material** - Material Design component library
- **TailwindCSS** - Utility-first CSS framework
- **OpenLayers** - Maps and geospatial visualization
- **Transloco** - i18n solution for translations
- **ApexCharts** - Charts and data visualization (via ng-apexcharts)
- **Quill** - Rich text editor
- **RxJS** - Reactive programming with observables

### API Integration

The frontend communicates with a Django REST API. The TypeScript client is auto-generated:

1. Backend exposes OpenAPI spec at `/swagger.json`
2. Spec is saved to `sandbox/spa/swagger.json`
3. `yasag` tool generates TypeScript client in `src/api/`
4. Services import and use generated API methods

To regenerate API client after backend changes:
```bash
make swagger    # Fetch latest OpenAPI spec
make apigen     # Generate TypeScript client
```

### Testing

- **Framework**: Jasmine + Karma
- Run tests: `npm run test` in spa directory
- Test files are co-located with components: `*.spec.ts`

### Docker Development

The spa service is defined in `sandbox/docker-compose.yml`:
- Runs Angular dev server on port 4200
- Hot-reload enabled via volume mounts
- Node modules persisted in Docker volume
